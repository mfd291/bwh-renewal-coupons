## 常见问题

### 续费账单出来后，还能补输优惠码吗？

官方续费说明没有提供在已有续费账单上补输新优惠码的保证。先看账单是否已经显示折扣；若没有，联系官方支持确认，不要假设旧码必然有效。

### 不付款会立刻删除 VPS 吗？

官方说明，账单逾期 7 天后服务会被暂停。暂停不等于可以无限期保留数据；具体账户状态及后续处理，应以官方通知和账户页面为准。不要把“还有宽限时间”当成延迟付款的计划。

### 关闭续费会不会只是不再自动扣款？

不是。官方说明，关闭续费后，服务会在续费日自动终止，也不会发送续费账单。它和“关闭自动扣款”不是同一件事，因为搬瓦工本身就不会自动扣除信用卡或 PayPal 款项。

### 能提前续费锁定旧价格吗？

官方知识库表示不提供提前续费。可以预先向账户添加余额，用来支付之后生成的账单；这与提前生成或提前支付某一期续费账单不同。
